# 🛒 Supermarket Program — Python

A beginner Python project that simulates a simple supermarket checkout system. It allows users to select products, enter quantities, calculate prices, and proceed through a basic checkout process.

This project was created as part of my journey into programming and learning Python.

## ✨ Features

- 🛍️ **Product Selection** — Choose products from the available options.
- 🔢 **Quantity Input** — Enter the quantity of the selected product.
- 💰 **Price Calculation** — Calculate the total price based on the product's unit price and quantity.
- ✅ **Order Confirmation** — Confirm the selected quantity before proceeding.
- 🔄 **Input Validation** — Handle invalid product selections and allow users to try again.
- 🎫 **Loyalty Card** — Includes a loyalty card feature.
- 🧾 **Discounts & Taxes** — Applies the discount and tax rules implemented in the program.

## 🛠️ Built With

- **Python 3**
- **Built-in Python features** — Variables, user input, conditional statements, loops, and arithmetic operations.

## 🚀 Getting Started

### Prerequisites

Make sure you have Python 3 installed on your computer.

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd YOUR_REPOSITORY_NAME
   ```

3. Run the Python file:

   ```bash
   python main.py
   ```

   If your system uses `python3`, run:

   ```bash
   python3 main.py
   ```

> Replace `main.py` with your actual Python filename if it is different.
